Docs

Dokumenterne bag spillet. Det øverste er til print og skal ligge på bordet; resten er baggrund og bliver bag skærmen.

Til print

  • Bedrifter — afkrydsningsark 216 bedrifter på elleve A4-sider. Én række pr. bedrift med navn og udløser, og fire felter til spillerne. Forsiden holder Class Box, og hver pakketype fylder to sider — Bronze for sig, Sølv og Guld sammen. Nederst i hver tabel er der stiplede rækker til dem du finder på undervejs. Åbn og tryk print

Husk at slå «print baggrundsgrafik» til, ellers forsvinder den grå tone der adskiller spillerkolonnerne fra teksten. Skalering 100 %.

Baggrund

  • Idékatalog Den samlede sandhed: hvad der er besluttet, hvorfor, og hvad der ligger på ventelisten. Gentager med vilje det der står i de to andre, så man kan læse ét dokument og have hele billedet.
  • Bedrifterne Alle 216, delt efter pakketype og niveau. Kilden til afkrydsningsarket — ret her, kør scripts/build_checklist.py, print igen.
  • Ideen bag spillet Præmis, tone, de fysiske kort, og hvordan bedrifterne tildeles ved bordet.
  • Generatoren Pakker, fordelinger, vægte, kort og print. Hvordan loot boxene er skruet sammen.

Alle bedrifter er skjulte. Både arket og bedriftslisten er DM-materiale.
